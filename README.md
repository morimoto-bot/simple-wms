# 簡易WMS（試作）

スマホのカメラでバーコード（JAN）を読み取り、入荷・検品・出荷・出庫・棚移動・棚卸ができる簡易WMS。**画面は単一のHTML、GASは倉庫（JSONの受け口）**に分けています。GASのWebアプリの画面（HtmlService）はiframe内でカメラが使えないため、画面だけをHTTPSで配信する構成です。

- 画面: [`index.html`](index.html)（単一ファイル。ZXing-jsで読み取り。ホーム画面に追加してPWAとしても使える）
- 倉庫: [`gas/Code.gs`](gas/Code.gs)（Googleスプレッドシートを9シート固定で使う）
- 設計: [`docs/01_設計メモ.md`](docs/01_設計メモ.md)／手順: [`docs/02_手順メモ.md`](docs/02_手順メモ.md)
- サンプル: [`sample/sample-master.csv`](sample/sample-master.csv)（ダミーの商品）

**状態: 試作。iPhone実機・GAS本番デプロイでの確認は、手順メモの「実機確認チェックリスト」のとおりこれから。**

## 使うまで（要点。詳細は手順メモ）
1. GASプロジェクトに `gas/Code.gs` と `gas/appsscript.json` を入れ、スクリプトプロパティ `APP_TOKEN`（**16文字以上**のランダムな文字列）を設定し、ウェブアプリとしてデプロイ（次のユーザーとして実行=自分、アクセス=全員）
2. `Code.gs` の `CONFIG.SPREADSHEET_ID` に自分のスプレッドシートのIDを入れる（空なら、スクリプトが紐づくスプレッドシート）
3. このリポジトリの `index.html` を開き（GitHub Pagesなら `https://<ユーザー名>.github.io/<リポジトリ名>/`）、⚙の設定にGASの `/exec` のURLと合言葉を**手入力**する
4. 設定画面で商品マスタを取り込む（`sample/sample-master.csv` の形式）

## セキュリティ（必ず読む）
- **このリポジトリとHTMLに、合言葉・スプレッドシートID・GASのURL・個人情報は入っていません**（入れないでください）。設定は、各自の端末の設定画面とGASのスクリプトプロパティだけに置きます
- GASは「全員（匿名を含む）」で公開されるため、`/exec` のURLを知っている人は誰でもアクセスできます。実質の防御は合言葉だけです（16文字以上必須）。URLと合言葉は別々に管理し、SNS・スクリーンショット・公開リポジトリに載せないでください
- スプレッドシートの共有設定は「制限付き」（所有者のみ）にしてください
- 詳しいチェックリストと、合言葉の再発行手順は `docs/02_手順メモ.md` の9章

## テスト
```
cd test && npm i && cd ..
node --test test/*.test.js
```
GASのコード（`gas/Code.gs`）を、メモリ上の模擬スプレッドシートで動かして検証します（PCだけで動きます）。画面の動作確認（疑似カメラ）は `node test/dev-server.js`。
